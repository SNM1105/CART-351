WEEK 1: SEPT 14th

This week summarized the foundational concepts on how the web works for building web apps. We discussed terminology; all things I knew about but never really took the time to fully understand. We got to play around with a dynamic web app, which I think was fun. It was cool to see how the other students in the class quickly took it upon themselves to see how far we could push it. We used it as a messaging board, tried to send gifs and images (which kinda failed, aside from sending links), and someone even asked if we wanted to grab some lunch after class. I think it's good to give people something so bare and see what they try to do with it. It might even generate a good idea for future projects. Speaking of projects, I'm working on something cool that I think this class will help me a lot in! It's a fun little student side project that I think will be cool and useful when I'm done with it. Anywho, Ciao!
